# My Budget Tracker

## Project Description

My Budget Tracker is a simple webpage designed to help users track their expenses in one place. The project was built using HTML and CSS as part of the Week 2 assignment.

## What I Built

The project includes:

- A Budget Tracker heading and logo
- An Add Expense form
- Expense name and amount inputs
- A category dropdown with five options
- An Add Expense button
- An expense table with sample data
- A collapsible How to Use section
- A budgeting tips video
- CSS styling and advanced CSS selectors

## Project Files

### index.html

The `index.html` file contains the structure and content of the Budget Tracker. It includes the form, expense table, multimedia elements, and details section.

### style.css

The `style.css` file controls the appearance of the webpage. It includes colors, spacing, borders, table styling, hover effects, focus effects, and advanced CSS selectors.

### logo.png

The `logo.png` file is the Budget Tracker logo displayed near the main heading.

## Features

### Expense Table

The table contains:

- Name
- Amount
- Category
- Date

It includes five sample expenses.

### Add Expense Form

The form contains:

- Expense Name
- Amount
- Category
- Add Expense button

The category dropdown includes Food, Transport, Rent, Entertainment, and Other.

### Multimedia

The page includes a Budget Tracker logo and an embedded budgeting video.

### Interactive Elements

The project includes a collapsible "How to use this tracker" section and hover effects on table rows.
